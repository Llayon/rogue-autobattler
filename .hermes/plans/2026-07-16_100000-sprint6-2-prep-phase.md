# Sprint 6.2: PREP phase с расстановкой

> **For Hermes:** TDD на каждый Task. RED → GREEN → commit. S6.2 добавляет полноценный placement screen перед каждым боем.

## Goal

Игрок может перед боём:
1. Видеть доску (grid 7x4) с текущими юнитами
2. Видеть bench (запасные юниты, если есть)
3. **Swap двух юнитов** на доске (клик A → клик B → swap)
4. **Move board → bench** (клик board → клик bench slot)
5. **Move bench → board** (клик bench → клик board slot)
6. Кнопка "Ready → SPACE" → BATTLE

## Текущий flow (S5.3+S5.4)

Round 1: PREP (auto) → SPACE → BATTLE → REWARD → MAP → next node
Round 2+: MAP → choose node → BATTLE → REWARD → MAP → next node

**Нет полноценного PREP перед round 2+** — MAP → BATTLE без расстановки.

### D2 — Click flow: select-then-act (StS-style)

Состояние клика: `_selected: Variant` (null / cell_index / bench_index).
- 1-й клик: select (highlight blue border)
- 2-й клик: target — swap/move based on source/target pair
- 3-й клик: clear selection

UI logic:
- board+board → swap two cells
- board+bench → move board unit to bench
- bench+board → move bench unit to board
- bench+bench → swap two bench slots
- same slot → deselect

   - round_index == 2..MAX_ROUND-1: `Phase.MAP` (выбор следующего нода)
   - round_index >= MAX_ROUND: GAMEOVER

Current code already has `if state.round_index >= 2: MAP else PREP`. Reuse.
