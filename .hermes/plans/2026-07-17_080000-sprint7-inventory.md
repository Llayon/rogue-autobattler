# Sprint 7.1: Inventory (минимальный осмысленный MVP)

> **For Hermes:** TDD на каждый Task. RED → GREEN → commit. S7.1 даёт полноценный inventory без equipping/active use.

## Goal

Игрок имеет persistent inventory с предметами:
- Приобретение через TREASURE service (random item), MERCHANT service (shop)
- Удаление через discard (manual)
- Сериализация в RunState (atomic save)
- UI scene (InventoryScene) с toggle по клавише `I`
- Items = реальные .tres ресурсы в content/items/

НЕ в scope (S7.2+):
- Equipping items на юнитов
- Active use (consumable use mid-battle)
- Item drops from combat
- Item categories / subtypes (consumable, equipment)

## Архитектурные решения

### D1 — ItemDef как data-only resource

Минимальный ItemDef (уже существует в `core/data/item_def.gd`):
```gdscript
class_name ItemDef extends Resource
@export var id: StringName = &""
@export var display_name: String = ""
@export var description: String = ""
@export var cost: int = 1
@export var tier: int = 1
@export var bonus_attack: int = 0
@export var bonus_defense: int = 0
@export var bonus_max_hp: int = 0
@export var bonus_attack_speed: float = 0.0
@export var bonus_crit: float = 0.0
```

### D2 — Items как stub Items (potion-style)

3 sample items с разными stats:
- **potion_strength.tres**: +5 attack, cost=2, tier=1
- **scroll_ward.tres**: +3 defense, cost=2, tier=1
- **amulet_vigor.tres**: +10 max_hp, cost=3, tier=2

### D3 — RunController API

```gdscript
func grant_item(item_id: StringName) -> bool  # добавляет в state.item_ids
func remove_item_at(idx: int) -> bool        # удаляет по индексу
func inventory_count() -> int                # count
func get_item_def_at(idx: int) -> Resource   # ItemDef lookup
```

### D4 — Service routing

TREASURE service: после золота grants random ItemDef (random.choice from ItemDB).
MERCHANT service: на фазе PREP показывает shop (shop_ui) — out of scope S7.1.

Wait — MERCHANT service имеется в S5.4:
```
elif node.type == "MERCHANT":
    set_phase(Phase.PREP, ...)
    _refresh_shop()
    GameBus.emit_shop_refreshed(...)
    # stay_in_current_phase
```

Реальный shop UI ещё нет — `_refresh_shop` обновляет state.shop_offer. В S7.1 я **не буду** трогать shop (out of scope). В S7.1 только:
- grant_item через TREASURE
- inventory scene UI
- I key toggle

### D5 — InventoryScene (UI)

`scenes/inventory/inventory_scene.gd`:
- Control overlay (на BattleScene), full-rect
- CenterContainer + PanelContainer (как reward_modal)
- Title "Inventory"
- VBox со списком предметов (кнопки с описанием)
- "Discard" button per item → remove_item_at
- "Close" button (X) → visible = false
- Visible по умолчанию false, показывается по нажатию `I`

### D6 — Input handling

BattleScene._unhandled_input ловит `KEY_I` для инвентаря.
InventoryScene сам ловит `KEY_ESCAPE` для закрытия.
