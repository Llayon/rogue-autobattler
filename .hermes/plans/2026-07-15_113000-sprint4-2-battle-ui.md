# Sprint 4.2: Battle UI (HUD + Cooldown + Damage Numbers + Summary)

> **For Hermes:** TDD на каждый Task. S4.1 уже дал smoke-инфраструктуру для scene/*.
> BattleView._draw() уже рисует HP-бары и статусы. Этот спринт — **то, чего реально нет**:
> HUD bar, cooldown indicators, floating damage numbers, end-of-round summary.

**Goal:** Игрок видит полную battle информацию во время боя:
- HUD: gold/lives/round/wins в верхней панели
- Cooldown indicator на юните (прогресс-кольцо для способности)
- Floating damage numbers (видно кто сколько получил)
- End-of-round summary ("Round 3 → 4! +5 gold")

**Architecture:**
- `BattleScene`: создать `HudBar` Control (PanelContainer + Labels) сверху
- `BattleView._draw()`: добавить cooldown indicator для активной способности + damage number overlay
- `core/utils/event_bus.gd`: добавить signal `damage_dealt(target, amount)` — emit из DamageEffect
- `core/battle/battle_runner.gd`: после `_on_battle_ended` emit `round_summary(...)` signal
- `BattleScene`: подписаться на signals, обновить HUD label'ы

**Tech Stack:** GDScript 2.0, Godot 4.7, TDD, existing scene/* pattern.

## Архитектурные решения

### D1: HUD layout

**Выбор:** PanelContainer вверху `BattleScene` (top = 48px height), внутри 4 Label:
- Round (e.g. "Round 3")
- Wins (e.g. "Wins: 2")
- Gold (e.g. "💰 50")
- Lives (e.g. "❤️ 1")

**Почему:**
- PanelContainer даёт красивый фон автоматически
- 4 labels = минимум информации для принятия решений
- Lives мало видно если lives=1 — но важно когда >1 (для multi-life мод)

### D2: Cooldown indicator

**Выбор:** Над юнитом, маленький полукруг показывающий прогресс (0% = full, 100% = empty = ready).
Использовать `Combatant.attack_meter.progress()`.

**Почему:**
- Не нагружает UI (1 draw call на юнита)
- Уже есть `attack_meter` в Combatant (см. attack_meter.gd)
- Визуально просто: дуга 270° (3/4 круга)

### D3: Floating damage numbers

**Выбор:** `GameBus.damage_dealt(target, amount, source)` signal.
`BattleView` подписывается, добавляет entry в `_damage_numbers: Array` с (cell, amount, time_remaining).
В `_draw()` рендерит числа рядом с юнитом 0.5s, потом удаляет.

**Почему:**
- Уже есть `GameBus.unit_damaged(amount, source)` — но он шлёт Combatant (не число). Добавим новый signal с конкретным уроном.
- Реальное использование: игрок видит «42» над гоблином когда его ударил воин
- Storage в `_damage_numbers: Array` с TTL (как в RTS)

### D4: End-of-round summary

**Выбор:** `BattleScene` подписывается на `battle_ended(winner_team)` signal. Через `await get_tree().create_timer(1.0).timeout` показывает Panel с Label "Round X → X+1! Gold: +5".

**Почему:**
- Простая UI без переходов между сценами
- await timer даёт паузу чтобы игрок увидел результат
- Не блокирует цикл боёв (после timer → продолжается PREP)

### D5: Damage signal — где emit?

**Выбор:** В `DamageEffect.apply()` после `t.take_damage(amount, source)`.

**Почему:**
- DamageEffect — single source of truth для нанесённого урона
- Уже есть `t.health.current_hp` после применения → можем посчитать dealt = pre - post
- emit `damage_dealt(target, dealt, source)` — точно по факту

**Step 2:** Emit в `damage_effect.gd`:
```gdscript
# После t.take_damage(amount, source):
var dealt: int = pre_hp - t.health.current_hp

    GameBus.emit_damage_dealt(t, dealt, source)
```

**Step 3:** В `battle_view.gd`:
```gdscript
var _damage_numbers: Array = []  # [{target_id, cell, amount, time_remaining}]

func _process(delta: float) -> void:
    # TTL для damage numbers.
    var new_list: Array = []
    for entry in _damage_numbers:
        entry["time_remaining"] -= delta
        if entry["time_remaining"] > 0.0:
            new_list.append(entry)
    _damage_numbers = new_list
    if not _damage_numbers.is_empty():
        queue_redraw()

func add_damage_number(target: Combatant, amount: int) -> void:
    _damage_numbers.append({
        "target_id": target.get_instance_id(),
        "cell": target.cell,
        "amount": amount,
        "time_remaining": 0.5,
    })
    queue_redraw()

func _on_damage_dealt(target, amount: int, _source) -> void:
    if target is Combatant:
        add_damage_number(target, amount)
```
