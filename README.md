# Rogue AutoBattler

Roguelike RPG AutoBattler на Godot 4.

## Запуск

1. Установи Godot 4.3+.
2. Открой проект: `Project Manager → Import → выбери project.godot`.
3. Нажми F5 (Play). Откроется минимальная тестовая сцена с одним юнитом против одного врага.
